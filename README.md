# Braintalk - Grok AI with Celebrity Voice TTS

Braintalk is a web application that allows users to interact with Grok AI and have responses converted to speech using celebrity voice models.

## Features

- Send prompts to Grok AI
- Convert responses to speech using celebrity voice models
- User authentication
- History of prompts and responses
- Voice selection

## Tech Stack

- **Backend**: NestJS, MongoDB, TypeORM, Redis
- **Frontend**: (To be implemented) React, Next.js
- **APIs**: Grok AI API, ElevenLabs API (for TTS)
- **Storage**: AWS S3 (for audio files)

## Getting Started

### Prerequisites

- Node.js (v14 or later)
- MongoDB
- Redis
- AWS account (for S3)
- Grok AI API key
- ElevenLabs API key
